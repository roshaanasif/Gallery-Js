**📸 Image Gallery**<br>

A simple and responsive **Image Gallery** built using **HTML, TailwindCSS**, and **JavaScript**.
The gallery displays **all photos by default**, and also provides a feature to **filter photos by category**.
Users can navigate through category-filtered images using **Next** and **Previous** buttons.

---

## 🚀 Features

### ✔️ Display All Photos

By default, the gallery loads **all available images** in a grid layout.

### ✔️ Category-wise Filtering

Users can select a category (e.g., cities ,buildings,beaches ) and the gallery updates to show only images from that category.

### ✔️ Next & Previous Navigation

Inside category mode, users can browse images with:

* **Next ➜**
* **Previous ◀**

### ✔️ Smooth Hover Effect

Images slightly pop-out on hover using TailwindCSS transitions.

### ✔️ Responsive Design

Fully responsive layout across mobile, tablet, and desktop.


## 🛠️ Technologies Used

* **HTML5**
* **TailwindCSS** – For utility-first styling
* **JavaScript (ES6)** – For dynamic filtering & navigation
